# Python packages the developer-only gates import. Nothing in the build or in CI
# needs these: `make lint` runs on the standard library alone, and pefile is
# read only by scripts/check_exports.py, which scripts/check_all_versions.sh
# (`make parity`) drives. Install with:
#
#   uv venv
#   source .venv/bin/activate
#   uv pip install -r scripts/requirements.txt
#
# The venv is not optional: `uv pip install` refuses to install outside one, and
# the `source` is what puts its python3 on PATH for the gate that reads this.
#
# Pinned so a parity verdict is comparable across machines; pefile parses the
# reference DLLs' export tables, and a different release could read them
# differently. The filename is plain requirements.txt because Dependabot's pip
# ecosystem only discovers that name, so the pin gets security and release
# updates proposed; it will not follow a floating range on its own.
#
# Each pin also carries the SHA-256 of every artifact PyPI publishes for it, so
# an install verifies the bytes instead of trusting the name. The digests below
# are the ones the index advertises for this release, each checked by
# downloading the artifact and hashing it. A version bump has to bring the new
# release's digests with it: a pin whose hashes name a different artifact fails
# the install rather than pulling unchecked bytes. scripts/gen_sbom.py carries
# the same digests into SBOM.cdx.json, so the inventory records the integrity of
# this package as well as its version.
